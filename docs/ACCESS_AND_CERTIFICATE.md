# Доступ к лекциям по коду и подпись самопроверки

## Что сделано

Каталог курса открыт: видно все 26 лекций и их названия. Сама лекция без кода не откроется — вместо неё показывается форма запроса кода. Код запоминается на этом устройстве на неделю, потом запрашивается снова.

Мастер-код снимает доступ и сохранённое ФИО на устройстве. Сценарий: компьютер в аудитории, сегодня сдавал один человек, завтра другой — преподаватель вводит мастер-код, следующий входит со своим кодом и вписывает своё ФИО. Кнопка «Сбросить доступ мастер-кодом» есть в форме запроса кода.

## Где лежат коды

Коды преподавателя хранятся в `config/access-codes.json`. Файл не публикуется и добавлен в `.gitignore`. Форма — `config/access-codes.example.json`.

```json
{
  "secret": "строка не короче 32 символов",
  "releaseCode": "МАСТЕР-КОД-НЕ-КОРОЧЕ-8-СИМВОЛОВ",
  "lectures": {
    "01-project-decisions": ["КОД-ЛЕКЦИИ-01"],
    "02-roles-views": ["КОД-ЛЕКЦИИ-02"]
  }
}
```

Ключ — идентификатор лекции из `public/course.json`. Значение — массив: один код на группу или несколько, если доступ выдаётся по одному на человека.

## Сборка

```
npm run compile:access
```

Скрипт читает `config/access-codes.json` и пишет `public/access-codes.json`: только SHA-256 хеши кодов, ключ подписи и хеш мастер-кода. `npm run build` вызывает `compile:access` сам.

Если `config/access-codes.json` отсутствует, скрипт ничего не перезаписывает и лекции без опубликованных хешей открываются свободно. Так ведётся разработка. Уже собранный и закоммиченный `public/access-codes.json` при этом сохраняется — именно его публикует GitHub Pages.

Код короче 8 символов после нормализации сборка отклоняет: короткие коды перебираются по хешам. Лекция, для которой код не задан, открывается свободно.

Смена любого кода требует пересборки и коммита нового `public/access-codes.json`.

## Как проверяется код

Код нормализуется: регистр, пробелы и знаки препинания отбрасываются, остаются символы `0-9` и `A-Z`. Хеш считается через WebCrypto `SHA-256` и сверяется со списком хешей лекции. Кириллица и латиница — разные символы, поэтому раскладка важна.

## Подпись результата самопроверки

В окне результатов самопроверки появляется блок **«Результат для преподавателя»**. Студент один раз вводит ФИО и нажимает «Подписать результат». Дальше ФИО зафиксировано до снятия доступа, а рядом показаны баллы, отпечаток кода, подпись и время.

Подпись — HMAC-SHA256 от строки:

```
pidis3-certificate-v1 | ФИО | лекция | баллы | всего | отпечаток кода | время | версия курса
```

Файл результата сохраняется кнопкой «Сохранить файл результата» — его и показывают преподавателю.

### Граница защиты, честно

Ключ подписи лежит в файлах сайта. Студент с инструментами разработчика может переписать ФИО и пересчитать подпись — остановить это на статическом хостинге нечем, нужен сервер, который подписывает сам.

Что при этом работает: отпечаток кода. Это четыре знака от SHA-256 кода лекции, и получить отпечаток чужого кода, не зная сам код, нельзя. При **личных кодах** отпечаток однозначно указывает, чей это результат, и подменять личность не нужно.

При **общем коде на группу** отпечаток одинаков у всех, личность по нему не определить, и остаётся только ФИО — то есть ровно то, что подделывается. Если нужна настоящая привязка личности к результату, коды должны быть личными.

## Проверка на стороне преподавателя

```
npm run verify:certificate -- путь/к/результату.json [код]
```

Скрипт сверяет подпись с ключом из `config/access-codes.json` и печатает ФИО, лекцию, баллы, отпечаток, время и версию курса. Если передан код, подтверждается отпечаток: при чужом коде выводится «отпечаток НЕ совпал», а вместе с подписью — `ПРОВАЛ` и ненулевой код возврата.

## Правки движка

Функции доступа и подписи живут в `vendor/access-runtime.js`, откуда копируются в движок. Правки интерфейса описаны в `scripts/engine-edits.mjs` и применяются командой `npm run engine:patch` из `postinstall`. Проверка `npm run engine:check` входит в сборку и падает, если движок не актуален.

## Очистка локальных данных

В браузере хранятся три ключа с префиксом `pidis3-`:

| Ключ | Что хранит | Снимает |
|:---|:---|:---|
| `pidis3-access:<путь>` | открытые лекции, срок и отпечаток кода | мастер-код или очистка данных сайта |
| `pidis3-identity:<путь>` | ФИО обучающегося | мастер-код или очистка данных сайта |
| `pidis3-identity:<путь>:cert` | подписанный результат последней лекции | новая подпись или очистка данных сайта |
