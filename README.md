# ПиДИС · 3 курс

26 лекций МДК.05.01 «Проектирование и дизайн информационных систем». Учебный кейс — WMS. 1 805 слайдов, 208 понятий, 104 вопроса и 416 заданий. Лекции закрыты кодом преподавателя, каталог открыт.

## Запуск

Node.js 24. Из корня проекта:

```sh
npm ci
npm run build
npm run preview -- --port 4176
```

Открыть <http://127.0.0.1:4176/2026-PISID3-lecture/>. Разработка: `npm run dev`. `BASE_PATH` задаёт путь размещения при сборке. Через `file://` сайт не запускается.

## Доступ к лекциям и подпись самопроверки

Каждая лекция открывается кодом преподавателя. Каталог остаётся открытым: он показывает все 26 лекций, но без кода лекция не откроется. Код запоминается на неделю; мастер-код снимает доступ и сохранённое ФИО на устройстве.

Коды лежат в `config/access-codes.json` — файл не публикуется и добавлен в `.gitignore`. Форма — `config/access-codes.example.json`. В сборку уходят только SHA-256 хеши, ключ подписи и хеш мастер-кода:

```sh
npm run compile:access
```

Если `config/access-codes.json` отсутствует, сборка ничего не перезаписывает и лекции открываются без кода. Код короче 8 символов сборка отклоняет.

После самопроверки появляется блок **«Результат для преподавателя»**: студент один раз вводит ФИО и подписывает результат. Подпись — HMAC-SHA256 от ФИО, лекции, баллов, отпечатка кода, времени и версии курса. Отпечаток кода — четыре знака от SHA-256 введённого кода, поэтому чужим кодом подпись не подделать.

Проверка на стороне преподавателя:

```sh
npm run verify:certificate -- results/ЛР-01.json PISID3-LR01-…
```

Скрипт сверяет подпись с ключом из `config/access-codes.json` и, если передан код, подтверждает отпечаток. При подмене ФИО, баллов или чужом коде выводится `ПРОВАЛ` и ненулевой код возврата.

Ключ подписи лежит в файлах сайта, поэтому студент с инструментами разработчика может переписать результат и пересчитать подпись. На статическом хостинге это не остановить без сервера, который подписывает сам. Подробности — в [docs/ACCESS_AND_CERTIFICATE.md](docs/ACCESS_AND_CERTIFICATE.md).

## Правки вендорного движка

Интерфейс приходит собранным: исходников движка в репозитории нет. Нужные изменения описаны списком замен в `scripts/engine-edits.mjs` и применяются из `postinstall`:

```sh
npm run engine:patch   # применить
npm run engine:check   # проверить, не пропатчен ли движок
```

`npm run build` начинается с `engine:check` и падает, если движок не актуален. Правки применены один раз и помечены в конце каждого файла движка, поэтому повторный запуск ничего не дублирует. Новые файлы, которых движку не хватает, лежат в `vendor/` и копируются в `node_modules`.

## Что убрано из интерфейса

Деление на семестры: подписи семестра в каталоге, на карточках, в шапке лекции и на каждом слайде; фильтр по семестру и подпись «5 и 6 семестры» в шапке каталога. Служебные кнопки: «Инструменты курса», «Вход», «Настройка перед занятием», «Начать занятие в двух окнах», «Материалы», «Сохранить PDF» на карточке лекции, «Изучено», «Повторить», «Закладка» под слайдом, «Тур по кнопкам». Из каждой презентации удалены слайды 2, 3 и 4 — «Основная литература», «Дополнительная литература» и «Материалы к занятиям»; всего 78 слайдов, нумерация осталась сплошной. Имя преподавателя на титульном слайде и в шапке каталога заменено на Белоусова Д. И.

## Работа с материалами

**[Гайд автора: единые источники и выпуск](public/project-guide.html)** — основной порядок работы без дубляжа. **[Справка преподавателя](public/guide.html)** — управление приложением.

Определения: `authoring/original-course.json`; примеры: `authoring/worked-cases.mjs`; предметные схемы: `authoring/case-visuals.mjs`; общая логика слайдов и сценариев: `scripts/generate-content.mjs`; индивидуальные поправки заметок: `authoring/teacher-overrides.json`. `npm run generate:content` согласованно обновляет курс, задания и опубликованный пакет заметок. Браузерные черновики сначала согласуйте с авторскими источниками.

Визуализация сетевых связей использует адаптер `scripts/diagram-layout-plugin.ts` и `src/network-layout.tsx`: при обновлении движка проверьте его совместимость.

Исторические `app`, `components`, `hooks`, `lib` не входят в новую сборку. Действующий интерфейс — `src`; движок закреплён архивом `vendor/olgakraven-lecture-engine-0.2.0.tgz`. Полный сценарий `public/teacher-pack.json` публичен. Личные правки остаются в браузере; экспортируйте их перед сменой версии. Окно аудитории не загружает пакет.

Схемы показывают отношения, условия и расчёты. 416 повторных слайдов с шаблонными схемами удалены; осталось 312 визуальных разборов: 208 сравнений и 104 предметные схемы. Все 208 понятий и 416 заданий сохранены. Старые ссылки на удалённые слайды открывают соответствующее сравнение.
